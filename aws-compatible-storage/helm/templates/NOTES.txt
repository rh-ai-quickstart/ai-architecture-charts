{{- if .Values.route.enabled }}

Access the Web UI via OpenShift Route:
{{- if .Values.route.host }}
  https://{{ .Values.route.host }}
{{- else }}
  kubectl get route {{ include "aws-compatible-storage.fullname" . }} -n {{ .Release.Namespace }} -o jsonpath='{.spec.host}'
{{- end }}

{{- else if .Values.ingress.enabled }}

Access the Web UI via Ingress:
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}

{{- else }}

Access the Web UI using port-forward:
  kubectl port-forward svc/{{ include "aws-compatible-storage.fullname" . }} 5000:{{ .Values.service.port }} 7480:{{ .Values.service.s3Port }} -n {{ .Release.Namespace }}

Then open:
  - Web UI: http://localhost:5000
  - S3 API: http://localhost:7480

{{- end }}
